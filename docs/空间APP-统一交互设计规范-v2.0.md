# 空间 APP 统一交互设计规范 v2.0

日期：2026-11-14。适用于空间猫咖、空间水族馆和意念神龙。来源为用户逐轮需求及确认；后续明确要求优先于本文。PICO Spatial SDK 6.1.9、当前模拟器6.2.1。尺寸为项目约定，不是PICO官方硬性标准。

## 1. 独立应用与品牌层级
- 每款游戏独立包名、入口、账号存储和素材目录，不在旧空间粒子APP里混用三个页面。
- 名称、slogan、当前对象名称必须分层。开屏：圆角产品图标约188dp，名称40sp/50sp粗体，slogan20sp/30sp常规次级色，间距12dp，不重复堆叠文案。
- 表单名称约32sp粗体，slogan用bodyMedium；主场景图标64dp/圆角18dp，名称headlineMedium粗体，slogan在下方bodyMedium次级色。
- 当前选中对象名称居中30sp半粗。内容边距24dp，区域间距12–16dp，同组控件间距8dp。
- 应用内Logo与系统启动器图标保持同一设计；启动器使用兼容PNG资源，避免遗留模板图标。
- 白色MindSoul支持标识与官网入口保留；原生PicoTheme、系统玻璃，不叠加多层不透明灰底。

## 2. 开屏、账号与协议
- 开屏先介绍产品，主按钮进入注册/登录；游客入口在右上角，使用轻量样式，与主要按钮区分。
- 默认邮箱+验证码登录，可切换密码登录；注册为邮箱、验证码、密码、确认密码。
- 本机测试验证码在页面显示，不发邮件，不假称验证邮箱归属。密码保存随机盐和摘要，不保存明文。
- 用户协议/隐私政策为下划线文字入口，原生可滚动弹窗，关闭后回到原表单。
- 外部网页、选取文件、拍照的取消/失败必须能返回，并保留原场景。协议应覆盖当前实际存储的数据。

## 3. 稳定的空间窗口
| 窗口 | 默认尺寸 | 相对主窗口位置 | 打开规则 |
| --- | --- | --- | --- |
| GameHome | 1000×720dp | 主窗口 | 开屏→表单→主场景 |
| Devices | 480×720dp | 左120dp | 点击脑机按钮后展开 |
| EEG/情绪识别 | 480×680dp | 右120dp | 与左窗同时展开，可独立关闭 |
| Controls | 360×340dp | 下80dp | 沉浸时显示，退出时关闭 |
| 水族馆素材 | 600×440dp | 下48dp | 进入水族馆后显示，可收起/重开 |
| 水族馆喜爱榜/心愿墙 | 600×480dp | 上64dp | 进入水族馆后显示，可收起/重开 |

固定主窗口ID、固定辅助tag，相同入口不可无限创建窗口。窗口位置不依赖当前焦点，不通过清空数据重置布局，不在每次重组时抢回用户手动位置。上下业务窗口不是所有应用强制标配，按各自玩法决定。

## 4. 操作与空间对象
- 默认生命感：缓慢漂浮、游动或轻跳；交互期间避免自动运动争抢用户操作。
- 原生hover反馈；单手选中/拖动，双手旋转/缩放，合理限制缩放范围，提供召回到面前。
- 选中后显示靠近对象的隐藏、删除按钮；隐藏保留对象与变换，提供可见的恢复入口；删除移出当前场景，不混同隐藏。
- 多对象列表采用差量添加/移除，避免操作一只时重置其余对象。
- 类型按钮以名称、颜色和选中标记共同区分，不仅靠颜色。主操作、次操作和破坏性操作在位置/文案上可辨认。
- 沉浸传递当前模型/状态，模型就绪后才收起主窗口；退出恢复主窗口，不重新生成固定对象。窗口和Stage坐标使用SDK转换API。

## 5. 脑机与反馈
- 脑机入口单独设计，点击才展开左右两窗。沉浸入口/脑机入口沿用紫色#6750A4与白字；上传蓝、相机绿可按功能采用，不全局覆盖主题。
- 设备名单：BrainLink Pro、博瑞恩、博睿康、MUSE S，均明确为模拟选择，不构成真实兼容认证。
- EEG支持3/32通道；32通道8条/页、四页；设备名和通道范围联动。暂停波形与暂停场景是不同操作。
- 模拟数据、情绪选项、专注力滑动条必须持续标明“模拟/非真实采集”，不得声称读取想象或治疗有效。
- 计时蓄能同时显示进度、环绕视觉/进度条和成功文字；可配短音效。取消、阈值跌落、重复点击、切换场景必须有确定的重置规则。

## 6. 各产品专属规则
### 空间猫咖
slogan“让你的意念Cat永远陪着你”；12色调色板与透明度；长按约2秒蓄能一圈后分身、提示及音效；9类模拟情绪；右窗为情绪识别。用户已确认长按蓄能和分身成功，不据此声称所有模式/真实EEG均通过。
### 空间水族馆
默认游动，无暂停按钮；五种内置生物，最多12只含隐藏；可导入自包含GLB2.0≤50MB，照片≤20MB保存本机；当前模拟器没有系统拍照应用，照片转3D明确待接入。上方本机喜爱榜按选中计数，日/周/月、北京时间更新；周一/每月1日为周期起点，连续操作同一对象不重复计数。心愿墙本机保存，200字/100条上限。用户已确认上下窗口、隐藏和恢复正常。
### 意念神龙（本轮首版）
名称由用户最新要求统一为“意念神龙”；沿用“让专注点亮你的愿望”。龙珠待机→填写心愿→模拟专注力≥70%持续10秒→神龙召唤。低于阈值清零计时，重启许愿重置进度。保留两款模型皮肤、蓄能/召唤音效和沉浸交互。不自动搬入水族馆排行榜/导入图库或猫咖情绪分身。

## 7. 数据与验收
- 本机账号、榜单、留言、导入素材都必须说明保存范围，云端未接入时不得写“全网榜”或“已上传”。照片浮雕不得冒充完整3D生成。
- 分别记录：编译、单元/设备测试、样式扫描、安装、界面可见、真实交互、真机性能。编译成功不能替代手势/相机验收。
- 验收路径：开屏→游客/登录→主场景→选择和主要玩法→隐藏/恢复/删除→脑机左右窗→沉浸/返回→失败和取消路径。
- 已验证的功能按证据逐条记录，不能把一个应用的确认自动扩展到另一个应用。
