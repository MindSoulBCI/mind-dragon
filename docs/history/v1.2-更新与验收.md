# 意念神龙 v1.2 更新与验收

- 上方独立 DragonWishes 心愿窗口：输入框、100字上限、上墙开关（默认关闭）、心愿看板、点赞排行榜、我的心愿。
- 每条公开心愿可点赞/取消点赞，按本机身份去重；作者可以撤回上墙或删除。数据持久化到本机，未接云端，不显示虚构用户。
- 普通模式10秒许愿倒计时，不依赖模拟专注力。龙珠随机漂浮，随倒计时汇聚，最后一起发光并召唤蓝色神龙；脑机模式保留模拟专注阈值规则。
- Blender制作七颗独立龙珠，内部1–7个MindSoul Logo；每颗支持选择、拖拽、双手旋转缩放、悬停发光、隐藏和删除。
- 蓝色神龙轻微漂浮，胡须与下颌缓慢运动。保留沉浸模式。
