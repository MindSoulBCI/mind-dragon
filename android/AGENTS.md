# 意念神龙 PICO
独立包名cn.mindsoul.pico.wishdragon，用户最新产品名意念神龙。保留Spatial SDK6.1.9，PICO模拟器6.2.1。
依据deliverables/空间APP-统一交互设计规范-v2.0.md与games-pico-design/wish-dragon/v1.1-change.md。已有源码是手工完善版本，不运行生成脚本覆盖。
主窗口GameHome1000×720，左右Devices/EEG480×720/480×680，间距120dp，仅脑机入口打开；Controls下80dp/360×340。所有界面使用PicoTheme/原生控件/系统玻璃。
主流程：上方DragonWishes独立窗口输入心愿→10秒许愿倒计时→随机汇聚龙珠全亮→蓝色神龙。仅开启脑机模拟后使用专注力≥70持续10秒规则。上墙默认关闭，心愿与点赞仅本机持久化；公开列表只显示shared记录。不声称真实脑电、云端心愿或愿望实现。
编译、测试、可见性、手势验收分别记录。
